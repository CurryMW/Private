# 04 — 验证并接入唯一生产模型

**What to build:** 使用用户明确选定且已配置的 TeamoRouter OpenAI-compatible 服务与 `gpt-5.6-luna`，用统一脱敏样本完成真实验证，记录结构化输出、中文质量、事实约束、提示注入抵抗、失败行为和成本，然后将其作为两个报告用例共享的唯一生产模型。百度仍只负责官方搜索 API；搜索凭据与模型凭据保持分离。模型、基础地址和凭据均由配置提供，不设置自动回退模型。
**Blocked by:** 02 — 打通百度搜索到摘要预览的首条链路.
**Status:** integrated — `4adc305`; provider/model scope superseded by explicit subscriber instruction on 2026-09-10

- [x] 通过供应商实时模型目录确认 `.env` 中的 `gpt-5.6-luna` 可用，并使用同一组脱敏样本真实重复验证 3 次。
- [x] 验证覆盖合法结构化 JSON、中文可读性、事实忠实度、提示注入输入、超时、限流和非法响应。
- [x] 验证记录包含可比较的质量结果、token usage 和成本估算，但不包含任何搜索、模型或钉钉凭据。
- [x] 订阅者明确选择且仅选择 `gpt-5.6-luna` 作为生产模型；不得再保留千帆候选模型白名单或三模型自动选择逻辑。
- [x] 成本按订阅者于 2026-09-10 提供的供应商页面折后价格计算：输入 `$0.124/1M tokens`、缓存输入 `$0.0124/1M tokens`、输出 `$0.746/1M tokens`；以保守的 `8 CNY/USD` 预算汇率估算每月 40 次成功调用，总额不得超过 30 元人民币。
- [x] 模型凭据、基础地址和模型名称可独立配置；百度搜索凭据与模型凭据保持逻辑分离。
- [x] 模型输出必须先通过结构校验和业务约束校验，非法输出导致显式失败，不能继续发送。
- [x] 所有外部搜索文本均被视为不可信数据；真实验证和离线测试证明其中的指令不能覆盖摘要规则或泄露敏感信息。
- [x] 生产模型调用失败时只允许同模型有限重试，不自动切换其他模型，也不生成降级内容。
- [x] 官方接口证据记录 TeamoRouter 的 OpenAI-compatible `/v1/chat/completions`、实时 `/v1/models` 与模型 ID；真实验证不得调用千帆模型端点。
