# 02 — 打通百度搜索到摘要预览的首条链路

**What to build:** 用一条可配置查询完成最小纵向链路：调用百度官方搜索 API、转换为标准搜索线索、交给摘要模型处理并生成钉钉消息预览。该链路只做本地 dry-run，不发送消息、不写成功状态，并允许旧采集链路暂时共存。
**Blocked by:** 01 — 建立独立报告应用接缝.
**Status:** integrated — 39c40ca

- [ ] 给定一条查询和伪造的百度成功响应，应用能够产出包含标题、摘要、来源、时间与链接的预览内容。
- [ ] 只调用百度官方搜索 API，不解析百度结果页，也不抓取目标网页正文。
- [ ] 搜索凭据通过配置注入；缺失时明确失败，日志、异常和预览中均不泄露凭据。
- [ ] 百度响应先转换为统一的搜索线索模型，异常字段、缺失链接和不支持的协议会被拒绝或安全忽略。
- [ ] 搜索结果及其文本一律按不可信输入处理，不得改变系统规则或触发额外工具调用。
- [ ] dry-run 不调用钉钉、不写成功状态，并通过退出结果清晰表达预览成功或失败。
- [ ] 使用伪造 HTTP 响应和临时状态的高层测试覆盖成功、百度错误响应和畸形响应。
- [ ] 旧采集链路仍可运行，为后续完整切换保留回退窗口。
