# 01 — 建立独立报告应用接缝

**What to build:** 在不改变当前生产行为的前提下，把报告编排收拢为可独立调用、可注入外部依赖的应用边界。为 AI 情报摘要和 GitHub 趋势报告划清独立入口，使后续切换数据源、状态和工作流时不再依赖真实网络、真实时间或真实钉钉群。
**Blocked by:** None — can start immediately.
**Status:** integrated — 810cf03

- [ ] 当前定时摘要的可观察行为保持不变，包括既有数据源、消息内容、发送条件和退出语义。
- [ ] AI 情报摘要拥有单一应用入口，并可注入时钟、HTTP 通信、状态存储和消息发送能力。
- [ ] GitHub 趋势报告拥有独立应用入口，并使用与 AI 情报摘要分离的运行状态。
- [ ] 应用结果能够明确区分预览、已发送、无内容、已处理和失败，调用方无需解析日志来判断结果。
- [ ] 外部协议细节被隔离在应用边界之外，核心用例可使用伪造 HTTP 响应和临时状态运行。
- [ ] 高层测试覆盖两个入口的成功路径以及至少一个显式失败路径。
- [ ] 现有测试全部通过，且本票据不提前删除旧链路。
